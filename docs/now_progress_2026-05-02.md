# 진행상황 정리 (기능명세서 항목 순서/표)
기준일: 2026-05-02

본 문서는 노션 “기능명세서”의 **항목 순서**를 그대로 따르며, 현재 구현 상태를 **구현/부분구현/미구현**으로 표시합니다.

- **구현**: 명세 핵심 UX/조건/데이터 흐름이 대부분 충족
- **부분구현**: 화면/기본 흐름은 있으나 명세 핵심 조건(수량/예외/정책/연동)이 일부 부족 또는 스텁/임시 처리
- **미구현**: 화면/로직이 없음 또는 명세 요구사항 미적용

## 최근 변경 요약(2026-04-20 → 2026-05-02)

- **i18n 품질 보강**
  - 하단 탭바 라벨 i18n 누락 해결
  - Android locale 리스트 환경에서 “미지원 언어 → 영어 fallback” 강제
  - 내정보 탭(embedded)에서도 우측 상단 언어 변경 버튼 노출
  - `%` 표기 공통 i18n 키로 통일
- **온보딩(언어 선택) UX 개선**
  - 로컬언어 목록 표기를 “국가명”이 아닌 “언어명”으로 변경
  - 대상언어 선택 시 하이라이트 + 체크 표시 강화
  - 대상언어 첫 진입 시 기본 선택 제거(미선택에서 시작)
