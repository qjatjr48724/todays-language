|---|---|---|
| 목적 | 자격증·교재·**정보·후기** | **실시간 대화**·실전 연습 |
| 형태 | 게시글·댓글 | 채팅방·메시지 |
| 언어 | 주제·시험별 | **학습 언어**별 방 분리 |

### 3번 — 필수 정책·가이드라인 (도입 전)

**2번과 공통으로 필요한 것**

- 커뮤니티 이용약관·가이드라인, 개인정보(메시지·로그), UGC 스토어 정책, 신고·차단·제재 절차 → **2번과 동일 문서에 「채팅」 장을 추가**하거나 별도 **채팅 이용 규칙**으로 분리

**채팅 전용**

- [ ] **방 입장 규칙**: 학습 언어(`targetLanguage`) 일치 사용자만 해당 언어 방 접근
- [ ] **1차 범위**: **텍스트만**. 사진·동영상은 모더레이션·악용(성적·사기·미성년) 대비 후 **별도 단계**
- [ ] **실시간 메시지 보관·삭제** 정책(보관 기간, 법적 요청 시 제공 범위)
- [ ] **1:1 연락처·외부 메신저 유도** 스팸·사기 방지 안내
- [ ] **언어 학습 목적** 외 목적(연애·광고·정치 선동 등) 금지 — 가이드라인에 명시
- [ ] **신고·차단** UI: 메시지·사용자 단위
- [ ] (권장) **초기 방 목록 공개** + 비공개 DM은 2차 검토(스토킹·괴롭힘 리스크)
- [ ] **Rate limit**: 초당/분당 메시지 수 제한(Functions)
- [ ] **미디어 도입 시 추가**: 이미지·동영상 **사전 검열 또는 신고 후 삭제**, CSAM·불법 콘텐츠 대응, Storage 규칙·용량 상한, Android/iOS **권한·스토어 심사**

**기술·보안**

- [ ] Auth 필수, Firestore/RTDB **Rules**로 방·메시지 쓰기 제한
- [ ] API 키·비밀은 Functions만. 클라이언트에 관리자 키 없음
- [ ] (선택) 자동 욕설 필터 + 반복 위반 자동 mute
