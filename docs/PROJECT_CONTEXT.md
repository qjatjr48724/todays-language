## 2. 프로젝트 개요

- **한 줄:** 초보자도 부담 없이, **매일 조금씩** 다양한 언어를 학습할 수 있게 돕는 **AI 기반 데일리 학습 앱**.
- **핵심 가치:** 적은 양 + 매일 반복 + 쉬운 접근성. 유료 강의/앱 부담을 줄이고 **가능한 무료** 제공을 지향 (상황에 따라 유료 전환 가능성은 열어 둠).
- **초기 타깃:** 한국인. **추후** 전 세계 사용자 — **모국어(로컬 언어)** 와 **학습 언어**를 각각 설정.
- **초기 학습 언어:** **한국어 / 일본어** 고정. 한국인에게 한국어는 모국어이므로 **단어 의미 중심**으로 학습.
- **추후 (한국어 학습 모드):** 단어·문장·속담(+ 의미) 등 확장.

---

## 3. 기술 스택 (대화에서 확정)

| 영역 | 선택 | 비고 |
|------|------|------|
| **모바일** | **Flutter** | 두 스토어(Android/iOS) 목표, 1인 개발에 적합 |
| **백엔드** | **Firebase** | Auth, Firestore 등. DB를 직접 서버에 깔아 관리하는 단계는 당분간 피함 |
| **AI** | **Firebase Cloud Functions**(또는 동급 서버)에서만 외부 API 호출 | **보안:** API 키는 앱에 넣지 않음 |

### 개발 환경 메모

- 주로 **Windows**, **Mac**에서도 작업 가능.
- **iOS** 빌드·스토어 제출은 **Mac + Xcode** 필요.
- 폴더 이름 변경은 가능; 변경 후 IDE에서 새 경로로 폴더 다시 열 것.

## 5. 운영·정책

- **인터넷 연결 필수** — 오프라인 동작 범위는 초기에 정하지 않음.
- **일일 리셋:** **한국 자정**, 타임존 **Asia/Seoul (KST)** 명시.
- **보안 원칙:** 앱(Flutter)에 API 키/비밀값을 두지 않으며, 외부 AI 호출은 Cloud Functions(서버)에서만 수행.
- **개인정보 보호**: 회원가입 시 개인정보 수집에 관하여 동의를 받고, 수집된 개인정보를 보호하고 사용자 환경을 안전하게 유지하도록 노력함.
- **인증 범위(현재):** 이메일 로그인만 활성화. 소셜 로그인(Google/Apple)은 **추후 보안 정책 정리 후** 재활성화.

2. **오늘의 문장** — 하루 **10개** (현재 앱 설정 기준)

**학습 공통:** 앱 UI 로케일(ko/en/ja) 기반 i18n + KST 일일 진도 키

## 13. 이후 추가할 기능 (계획)

1. **사용자 간 채팅 기능**
   - 사용자가 “대화하고 싶은 언어”를 선택하면, **선택한 언어의 채팅 서버(채널/룸)** 로 접속
   - 같은 언어를 선택한 사용자끼리 해당 언어로 대화·소통하여 **실전 활용/회화 능력 향상**

2. **언어별 기초 문자표 마무리**
   - 기초 문자표(정적) 구현 이후, 데이터/UX/정합성 측면의 polish 진행

3. **가이드 느낌의 기본 회화 문서 페이지**
   - 여행 등 실제 상황에서, **상황·장소별로 어떤 대화를 나누는지** 예시를 제공하는 회화 가이드

4. **앱 스킨(꾸미기)**
   - 테마/스킨을 통해 앱 외형을 커스터마이징(코스메틱)
   - 핵심 학습 플로우 안정화 이후 도입(우선순위 3순위)
